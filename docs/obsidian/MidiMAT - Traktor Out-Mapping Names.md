# MidiMAT - Traktor Out-Mapping Names
Back to [[MidiMAT]]

Pick the CC in the dropdown next to **Learn** (Learn works only for inputs). Assignment = fixed deck/unit, never Focus.

| Hardware | Add Out… entry | Assignment |
|---|---|---|
| EQ HI/MID/LOW | Mixer › EQ › High/Mid/Low Adjust | Deck A–D |
| FLTR knob | **Mixer › Mixer FX Adjust** (no "Filter" entry) | Deck A–D |
| Gain | Mixer › Gain Adjust | Deck A–D |
| Channel fader | Mixer › Volume Adjust | Deck A–D |
| Headphone cue | Mixer › Monitor Cue On | Deck A–D |
| Round FX on/off (Z1) | Mixer › Mixer FX On | Deck A–D |
| FX select 1–4 (Z1) | Mixer › Mixer FX Selector | Deck A (verify) |
| Crossfader | Mixer › X-Fader › Position | Global |
| Cue mix / cue vol / main | Mixer › Monitor Mix / Monitor Volume / Master Volume Adjust | Global |
| FX Dry/Wet | FX Unit › Dry/Wet Adjust | FX Unit 1–4 |
| FX knobs 2–4 | FX Unit › Knob 1–3 (after Dry/Wet) | FX Unit 1–4 |
| FX on / buttons 2–4 | FX Unit › Unit On / Button 1–3 | FX Unit 1–4 |
| Play / Cue / Sync | Deck Common › Play/Pause / Cue / Sync On | Deck A–D |
| Loop on / size | Deck Common › Loop › Loop Active On / Loop Size Selector | Deck A–D |
| Track loaded | Deck Common › Deck is Loaded (out-only) | Deck A–D |
| Browse scroll | Browser › List › Select Up/Down | **Global only** |

Tip: X1 MK3 sleeps — press a button to wake it (knobs don't).
